## 結錯帳或客人退款：作廢訂單

### 什麼時候用
- 結帳後才發現點錯商品、數量或付款方式
- 客人要退貨退款
- 預購取件按錯人

結帳**之前**發現錯誤，不用作廢：在購物車按「取消」刪掉最後一件（長按清空），或在結帳畫面按「返回」修改。

### 步驟
1. 到「報表」，展開「本日交易明細」。
2. 找到那一筆，按「作廢」。
3. 看一下確認框：會寫要退給客人多少錢、用什麼方式付的。
4. 選原因（結錯帳／客人退款），或自己打字，也可以不填。
5. 按「確定作廢」。

### 作廢後會怎樣
- 紀錄**不會消失**，會變成刪除線並標「已作廢」，事後對帳查得到。
- 本日營收、Excel 報表都會扣掉這筆。
- 庫存自動加回去。
- 如果是預購取件，預購單會改回「未取件」。

### 常見情況
- **結錯帳**：作廢錯的那筆 → 回「銷售」重新結一筆正確的。
- **只退一部分**：整筆作廢 → 重新結一筆客人留下的商品。
- **預購 B 有加購**：尾款和加購是兩筆，要分別作廢。

### 注意
- 作廢**不能還原**，按之前請確認是對的那一筆。
- App 只改帳本。現金請當場退給客人；電子支付請到該支付 App 退款。
- 封存的場次不能作廢。
